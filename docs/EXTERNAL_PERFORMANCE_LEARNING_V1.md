# ContentEngine External Performance Learning v1

## Зачем

Мини-ИИ должен учиться не на красивой подписи и не на числе просмотров, а на
структурированных бизнес-результатах. Этот контур превращает внешние наблюдения
в **кандидаты для ограниченных A/B-тестов**, а не в команды второй модели.

## Что показал аудит двух исходных файлов

### Harly · топ роликов WW · 24–30 июля 2026

Исходный файл сам фиксирует ограничения атрибуции:

- 968 найденных публикаций;
- 316 публикаций с WW;

- 53 уникальных WW сопоставлены с Harly;

  заказы нельзя честно распределить между роликами;
- WW, отсутствующий в top-100 ответа WB, является **цензурированным пропуском**,

метрики использует только как fallback.

## Исправленные классы ошибок

### 1. «Ролик только 8 секунд»

Восемь секунд больше не являются обязательной длительностью:

- Gen4 Turbo: `2 / 5 / 8 / 10` секунд;
- Seedance 2 Fast: `4 / 8 / 12 / 15` секунд;
- Seedream 5 Lite: фото, длительность `0`.

Если по категории нет зрелых наблюдений длительности, система запускает
контрольный эксперимент:

- Gen4: `5` против `8` секунд;
- Seedance: `8` против `12` секунд.

Рекомендованная длительность появляется только после минимум двух сопоставимых
длительностей, достаточной поддержки каждой и устойчивого разрыва бизнес-оценки.

### 2. Выбор «успешного ролика»

Победитель выбирается только внутри одного контекста:

`категория → SKU → площадка`.

В score входят:

- заказы в день атрибуции — основной вес;
- proxy-конверсия заказ/корзина;
- продажи в день.

Просмотры не входят в score. Один автор может дать не более одного кандидата,
чтобы крупный аккаунт не заполнил обучение клонами одного результата.

Исключаются:

- WW-пакеты нескольких роликов в один день;
- строки без подтверждённой атрибуции;
- статические посты из video-policy;
- top-100 miss, который нельзя считать нулём;
- незрелые метрики;
- активация без human QA и подтверждённых прав.

### 3. Новая категория товаров

Новая категория не копирует winner другой категории. Иерархия:

1. точный SKU;
2. эта же категория;
3. безопасный глобальный control.

Если SKU и категория новые, система создаёт три arm-а:

- control `demonstration`;
- гипотеза A;
- гипотеза B.

Никакого автоматического winner-id нет. После накопления matched evidence
система может перейти в режим `60% проверенный паттерн / 20% control / 20%
ограниченное исследование`.

## Trust boundary

В машинный профиль не входят:

- raw URL;
- подпись или текст страницы;
- имя автора;
- model-generated `concise_instruction`;
- claims и факты о товаре;
- лицо, музыка, слоган или точная последовательность кадров.

В provider prompt может попасть только детерминированный фрагмент из
allowlisted enum-профиля. Внешние наблюдения не активируются автоматически.
