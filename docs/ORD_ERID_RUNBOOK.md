# ОРД / ERID: порядок маркировки рекламного поста руками

Дата: 2026-09-03. Область: рекламные посты (реклама товара третьего лица
или своя реклама с объектом рекламирования). Для ORGANIC-постов в
собственном канале без объекта рекламирования третьего лица маркировка
не нужна — чек-лист внизу.

## Роли

- **Сергей** — доступ к кабинету ОРД (решение pub-2: чей кабинет — для
  пилота рекомендован кабинет ИП, ВК ОРД бесплатный) и договоры
  рекламодателя.
- **Оператор** — регистрация креатива в ОРД, получение ERID, пост.
- **Алисия** — сверка ERID в живом посте при подтверждении
  (compliance-чекбокс формы).

## Порядок на каждый рекламный пост

1. **Разово на рекламодателя**: договор зарегистрирован в кабинете ОРД;
   реквизит договора идёт в поле contract_ref формы.
2. **До публикации**: оператор загружает креатив (видео + текст) в
   кабинет ОРД → получает **ERID** (токен).
3. ERID вносится в формы портала:
   - «Одобрить и разместить» — поле erid;
   - «Запланировать публикацию» — erid, advertiser (рекламодатель),
     ord_provider, contract_ref.
4. Автоподпись «Реклама. ‹рекламодатель›. erid: ‹токен›» собирает
   **сервер** — руками её не писать и не править.
5. Пост выходит с готовой подписью; Алисия сверяет ERID в живом посте
   при подтверждении final_url.
6. **Ежемесячно**: отчётность/разаллокация актов в кабинете ОРД.
   Обязанность НЕ кончается постом; забытая отчётность — штраф по
   ст. 14.3 КоАП.

## Когда ORGANIC законен (без ERID)

Все три условия сразу:
- пост в собственном канале команды/клиента;
- нет объекта рекламирования третьего лица (не продвигаем чужой товар);
- нет призыва к покупке чужого товара/услуги.

Сомнение = считать рекламой и маркировать. Решение о рекламном статусе
принимает руководитель, не оператор (правило вшито в чек-лист карточки
размещения).
