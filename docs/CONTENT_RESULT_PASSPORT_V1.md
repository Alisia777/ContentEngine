# Паспорт ролика v1 (контур №2)

Состояние на 27.08.2026, сборка `.29`. Одна server-owned read-модель для
всех экранов; термин пользователя — «Паспорт ролика» (не lineage).

## Где открывается

- Dock-приложение **«Паспорта»** (`/workspace/passports`): реестр готовых
  роликов проекта (превью-кадр, товар, движок, цена, метрики кратко) →
  полный срез. Deep-link: `?media=<uuid>`; фильтр по товару `?product=<uuid>`.
- Кнопка «Открыть паспорт» в архиве генераций.

## Состав среза

Ролик (плеер, параметры, sha) → Зачем создан (гипотеза из МАНИФЕСТА — точная
версия момента bind; у legacy честное «не была указана») → Из чего создан
(плитки материалов с ролью, sha в подсказке, «оригинал: youtube…» у
исходника со штампом происхождения) → Задание (версия ТЗ, раскрываемый
compiled_prompt) → Производство (движок, оценка/факт денег, манифест) →
Публикации → Статистика → История.

## Правила статистики (ТЗ 4.11)

Сервер отдаёт только числители и знаменатели; формулы считает экран:
CTR = clicks/views; клик→заказ = orders/clicks; просмотр→заказ =
orders/views; выручка на 1000 = revenue/views×1000. Ноль в знаменателе —
«Недостаточно данных», NaN/Infinity исключены. Зрелость снимка:
observed_at ≥ published_at + 72 часа; предварительные помечаются.

## Манифест происхождения (ТЗ 4.9)

`generation_provenance_manifests` (202608260007): append-only снимок в момент
bind (триггер на финальную запись bind'а — платный контур не переписан):
продукт, версия ТЗ + prompt_hash, материалы с sha256, движок, гипотеза
(точная версия из выбора запускавшего). Canonical hash самопроверяется;
replay идемпотентен, другой payload — отказ; generated-результат не может
числиться исходником товара (bind откатывается).

## RPC

- `creator_content_passport_registry` — реестр (bounded 200).
- `creator_content_result_passport` — срез одного ролика.
Оба: volatile (current_profile_id пишет профиль — read-only транзакция
шлюза ломала stable-вариант), security definer, ACL по членству и проекту,
missing_sections честно перечисляет отсутствующее.

## Тесты

`tests/test_workspace_content_passports_v1.py`. Боевые уроки зафиксированы:
секционный контур вместо сателлитного модуля (вечная «загрузка» в окне),
volatility, техподробность в карточке ошибки.
