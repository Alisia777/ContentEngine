# Манифесты исторических кейсов ИИ

Каталог хранит только схему и обезличенный шаблон. Данные из пользовательских
Excel-файлов здесь не зафиксированы и не были придуманы вручную.

- `manifest-v1.schema.json` — машиночитаемый контракт.
- `manifest-v1.template.json` — валидный шаблон-заглушка; все значения `replace-*`
  и нулевые хеши нужно заменить результатом проверенного парсера.

Манифест отделяет исходные факты от вывода команды. `outcome=review` означает,
что кейс не должен становиться правилом «хорошо / плохо» без решения человека.
Низкая выборка, окно атрибуции, неизвестная категория и конфликт SKU — причины
для `review`, а не для автоматической негативной метки.

Проверка без сети:

```powershell
python scripts/import_ai_historical_cases.py path\to\manifest.json
```

Запись описана в `docs/AI_HISTORICAL_CASE_IMPORT.md` и требует явного
`--commit`. При записи CLI не отправляет кейсы из JSON напрямую в БД: он
просит authenticated Edge-функцию заново разобрать уже зарегистрированный
`source_id`.
